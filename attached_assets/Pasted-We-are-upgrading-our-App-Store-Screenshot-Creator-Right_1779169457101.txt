We are upgrading our App Store Screenshot Creator.

Right now we only have COLOR THEMES.
We want to introduce a second layer called PATTERNS (texture/style overlays)
so users can mix:

Theme (color) + Pattern (style)

This must work in real-time in the editor preview.

-----------------------------------------
GOAL
-----------------------------------------
Add a new "Pattern" section below "Theme" in Slide Settings.

User can choose:
Pattern:
- None
- Mesh
- Grain
- Glass
- Blobs
- Grid
- Glow
- Paper
- Depth

Also add:
Pattern Intensity slider (0–100)

This pattern is rendered as an overlay layer ABOVE background color
but BELOW device mockup and text.

-----------------------------------------
IMPLEMENTATION DETAILS
-----------------------------------------

1) Create a new pattern layer div inside each slide:

<div class="pattern-layer"></div>

Position:
absolute
top:0; left:0; right:0; bottom:0;
pointer-events:none;

z-index order:
background color (base)
pattern-layer
content (device, text)

-----------------------------------------
2) PATTERN CSS
-----------------------------------------

PATTERN: Mesh
Use radial-gradient blobs with blur.

PATTERN: Grain
Use noise PNG overlay with opacity control.

PATTERN: Glass
Use backdrop-filter: blur() with gradient light.

PATTERN: Blobs
Use multiple radial-gradient organic shapes.

PATTERN: Grid
Use repeating-linear-gradient for grid lines.

PATTERN: Glow
Use radial-gradient light glow from corners.

PATTERN: Paper
Use paper texture image overlay.

PATTERN: Depth
Use vignette + bottom shadow gradient.

-----------------------------------------
3) JAVASCRIPT STATE
-----------------------------------------

Extend slide state:

slide = {
  theme: "Clean Light",
  pattern: "Mesh",
  patternIntensity: 40
}

-----------------------------------------
4) RENDER FUNCTION
-----------------------------------------

When pattern changes, update .pattern-layer style dynamically.

Example:

function applyPattern(pattern, intensity) {
  const layer = document.querySelector('.pattern-layer');

  switch(pattern) {
    case "Mesh":
      layer.style.background = `radial-gradient(circle at 20% 30%, rgba(255,0,150,${intensity/100}) 0%, transparent 60%),
                                radial-gradient(circle at 80% 70%, rgba(0,200,255,${intensity/100}) 0%, transparent 60%)`;
      layer.style.filter = "blur(60px)";
      break;

    case "Grid":
      layer.style.background = `repeating-linear-gradient(
        0deg,
        rgba(255,255,255,${intensity/200}) 0px,
        rgba(255,255,255,${intensity/200}) 1px,
        transparent 1px,
        transparent 40px
      ),
      repeating-linear-gradient(
        90deg,
        rgba(255,255,255,${intensity/200}) 0px,
        rgba(255,255,255,${intensity/200}) 1px,
        transparent 1px,
        transparent 40px
      )`;
      break;

    // implement all patterns similarly
  }
}

-----------------------------------------
5) UI
-----------------------------------------

Under Theme selector add:

Pattern dropdown
Intensity slider

-----------------------------------------
EXPECTED RESULT
-----------------------------------------

User can create combinations like:
- Midnight + Glow
- Arctic + Grid
- Sunset + Mesh
- Clean Light + Grain

This should feel like premium App Store design presets
that Canva/Figma do not provide.

Keep performance smooth.
Do not re-render device/text when pattern changes.
